Booking a furnished apartment for a short stay in Pakistan? Don't risk your money or comfort. This essential checklist covers everything to verify before you pay — from host verification and amenity accuracy to payment safety and red flags.

## Pre-Booking Verification Checklist

### 1. Host Verification (Most Critical)
- [ ] **CNIC Verified** — Host's CNIC checked against NADRA Verisys (mandatory on Kor Da)
- [ ] **Verification badge visible** on host profile
- [ ] **Host responds on WhatsApp** — save number, test response time
- [ ] **Host provides property address** (not just area)
- [ ] **Ownership/authorization proof** available on request

### 2. Property Photos & Description Accuracy
- [ ] **Reverse image search** photos — no stock image matches
- [ ] **Video tour available** — request if staying 7+ nights
- [ ] **Photos show:** every bedroom, bathroom, kitchen, living, balcony, building exterior, view
- [ ] **Recent photos** — ask when photos were taken
- [ ] **Description matches photos** — bed count, kitchen appliances, AC units visible

### 3. Amenity Verification
**Must-haves (confirm each):**
- [ ] High-speed WiFi (ask for speed test screenshot)
- [ ] AC in **all** rooms (not just living room)
- [ ] Full kitchen: stove, fridge, microwave, cookware, utensils
- [ ] Geyser/hot water (gas or electric)
- [ ] UPS or generator backup (critical in Pakistan)
- [ ] Washing machine (in-unit or building access)
- [ ] Parking (dedicated slot vs street)
- [ ] Drinking water (filter/dispenser or bottled provided)

**Nice-to-haves:**
- [ ] Iron/steamer + board
- [ ] Study desk & chair
- [ ] Balcony/terrace furniture
- [ ] Dishwasher
- [ ] Gym/pool access (building)
- [ ] Daily/weekly housekeeping (extra cost?)

### 4. Verified Reviews (Only Trust These)
- [ ] **Platform verifies reviewers** — only guests with completed paid stays (Kor Da does this)
- [ ] **Minimum 3+ reviews** for confidence
- [ ] **Recent reviews** (last 3-6 months)
- [ ] **Detailed reviews** mentioning specific amenities, host responsiveness, issues
- [ ] **Response to negative reviews** — host addresses concerns professionally
- [ ] **Dual-blind system** — neither party sees other's review until both submitted (Kor Da)

### 5. Location Verification
- [ ] **Exact address** provided (not just "G-11")
- [ ] **Google Maps location** matches description
- [ ] **Distance to your destination** verified (hospital, university, office)
- [ ] **Neighborhood safety** — ask host about area at night
- [ ] **Noise level** — main road vs internal street, floor number
- [ ] **Essentials nearby:** pharmacy, grocery, ATM, mosque, food

## Contract & Policy Checklist

- [ ] **Cancellation policy** understood (flexible / moderate / strict)
- [ ] **Refund policy** for: property mismatch, host cancellation, medical emergency
- [ ] **Check-in/out times** confirmed (typically 2 PM / 12 PM)
- [ ] **Late check-in** process (smart lock, key pickup, host meet)
- [ ] **Guest count limit** — extra guest fees?
- [ ] **Smoking/pet/party policies** — avoid surprises
- [ ] **Damage deposit** — amount, refund timeline, deduction criteria
- [ ] **Utility caps** for monthly stays (electricity/gas fair usage)

## Red Flags — Walk Away If You See These

| Red Flag | Why It's Dangerous |
|----------|-------------------|
| Host insists on cash/bank transfer to personal account | No protection, likely scam |
| No CNIC verification badge | Anonymous host, no accountability |
| Photos look professional/staged (stock images) | Property may not exist or look different |
| Price 30%+ below market rate | Bait for advance payment scam |
| Host pressures "pay now or lose it" | Urgency tactic to bypass verification |
| No WhatsApp/direct contact provided | Can't verify host identity |
| No reviews or only 5-star generic reviews | Fake reviews likely |
| Host refuses video tour for 7+ night stay | Hiding property condition |
| Address withheld until payment | Classic scam pattern |
| Multiple listings, same photos, different areas | Scammer recycling content |
